## Evidence matrix

All fixtures used temporary homes and knowledge roots. Runs used Python 3.14.7, PyYAML 6.0.3, pytest 9.1.1, SQLite 3.53.4 with FTS5, Node 22.22.1 and Git 2.47.1. The capture cases use stdlib unittest. Python 3.12.9 without site packages also passed the PKC and DEKC capture cases. RKC CI installs PyYAML; the source case and release search suite also passed with the built-in subset parser under `python -S`. SAC's local CI imports PyYAML to parse workflows. pytest is needed for the discovery commands below. The Node suite uses Node's built-in test runner.

Run from the corresponding source checkout with an empty temporary home and knowledge root. Keep the interpreter from the test environment on PATH for subprocesses. Tests that create Git repositories need a synthetic Git identity. To replay a PR's gold case against an older release, place its unmodified `tests/test_source_recall.py` in a temporary `tests/` directory next to a `scripts/` symlink to the release checkout. The tests create their own inputs. The fixture titles, paths, units, source bytes and absence labels serve as ground truth.

## Bounds, missing inputs and outstanding behavior

These checks used temporary copies of the shipped fictional samples. For PKC, SAC and DEKC, run the listed seed with `python3 scripts/<pack>_pack.py SEED --bundle BUNDLE --json`. For RKC use `rkc_pack.py ID --root BUNDLE`. For Core use `sbc_common.py pack --bundle BUNDLE --root SEED --summary`. Compare the same invocation with `SECOND_BRAIN_WINDOW_TOKENS=400`, then with a missing seed or bundle. Budget estimates are local heuristics.

| Surface and seed | Window of 400 versus default | Missing inputs and search fallback |
|---|---|---|

The release Core two-session test intermittently fails on its second merge with an add/add conflict in `knowledge/write-events/index.md`. Repeating `python3 -m pytest -q tests/test_sbc.py -k isolation_two_sessions` on a clean v0.3.8 checkout with a temporary home reproduces it. This test exercises writes. The read-only card regression passes independently. RKC top-1 staleness and its window handling, SAC/DEKC synthetic one-node packs for absent seeds, and Core's missing-absolute-seed exception remain separate runtime findings.
