# User guide — Second Brain Core

## 1. Install the plugin

See the README.

## 2. Init catalogs

`/sbc-init`

## 3. Capture

`/sbc-capture` then name a type and a title.

## 4. Pack and retrieve

`/sbc-pack` with a root concept when you start a write. For Q&A, use
`/sbc-retrieve` so the pack stays in a child (`docs/RETRIEVAL.md`).

## 5. Share

The same `knowledge/` tree is readable by sibling plugins and by local jobs on disk.
